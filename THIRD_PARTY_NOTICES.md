## USDA-ARS Yield Editor 2

Yield Data Cleaner is inspired by filtering concepts and workflows visible in
USDA-ARS Yield Editor 2 source supplied separately to the project. Yield Data
Cleaner is a new Python/PyQGIS implementation and does not distribute the legacy
VB6 project, executable, proprietary strip-chart OCX, or phase-correlation OCX.

The local `YE2code` directory is a development reference and is excluded from
the public plugin package.
